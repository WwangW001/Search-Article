## Query Patterns

Use combinations of these patterns:

- `<topic> survey 2025 2026`
- `<topic> benchmark`
- `<topic> dataset`
- `<topic> state of the art`
- `<topic> arXiv`
- `<topic> OpenReview`
- `<topic> GitHub`
- `<method> for <domain>`
- `<dataset> <method>`
- `<venue> <topic> 2025 2026`
- `<adjacent field method> transfer to <target domain>`

## Screening Rubric

Score or rank papers using:

- Relevance to the user's exact question
- Novelty compared with prior work
- Evidence quality and evaluation design
- Venue, workshop, or community signal
- Recency and follow-up activity
- Code, data, and reproducibility
- Applicability to the user's intended domain

## Report Template

1. Scope and assumptions
2. Search sources and query strategy
3. High-priority papers
4. Thematic clusters
5. Datasets, benchmarks, and code
6. Trends and gaps
7. Recommended reading path
